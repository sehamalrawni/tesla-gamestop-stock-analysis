# Tesla vs GameStop – Stock Price & Revenue Analysis

Analysis of historical stock prices and quarterly revenue for **Tesla (TSLA)** and **GameStop (GME)**, built as part of the IBM Data Science Professional Certificate.

## What I did
- Pulled full historical share-price data with the **yfinance** API
- Scraped quarterly revenue tables from the web with **requests** and **BeautifulSoup**
- Cleaned the revenue data with **pandas** (removing symbols and empty rows, converting types)
- Built a two-panel chart per company with **matplotlib** to compare share price against revenue over time

## Tools
Python · pandas · yfinance · BeautifulSoup · matplotlib · Jupyter Notebook
